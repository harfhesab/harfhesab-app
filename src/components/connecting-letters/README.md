# اتصال حروف (connecting-letters) — نسخه‌ی بازنویسی‌شده

API کامپوننت هیچ تغییری نکرده است؛ صفحه‌ها مثل قبل از آن استفاده می‌کنند:

```jsx
<ConnectingLetters
  type="stage-game"            // stage-game | package-game | harf-akhar | word-game
  data={data}
  stageNumber={stageNumber}
  saveMainWordBuilded={...}
  saveNewAdditionalWordsBuilded={...}
  saveNewHiddenWordsBuilded={...}
  completedOperation={...}
  saveUserHelpRequests={...}
  timeLimitData={...}          // اختیاری
  gameTimeIsOver={...}         // اختیاری
/>
```

## نصب

1. پوشه‌ی `components/connecting-letters` پروژه را **کامل** با این پوشه جایگزین کنید. این فایل‌های قدیمی دیگر
   استفاده نمی‌شوند و باید حذف شوند:
   - `components/FloatingCard.tsx` و `components/FloatingCardList.tsx`
   - `components/word-display/PlaceholderSquare.tsx`، `WordPlaceholderRow.tsx`،
     `SelectedCardWithAnumation.tsx` و `SelectionProgressCircle.tsx`
   - `utils/Generateinitialpositions.ts`
   - از نسخه‌ی اول همین بازنویسی: `components/board/TileArt.tsx`، `components/board/TileSprite.tsx` و
     `components/word-display/SlotWord.tsx`
2. **مهم — فونت:** Skia فونت‌های ثبت‌شده در React Native را نمی‌بیند و فایل فونت را خودش بارگذاری می‌کند.
   در `constants/theme.ts` مقدار `LETTER_FONT` را به فایل ttf فونت «YekanBakh-ExtraBlack» اشاره دهید
   (همان فایلی که `text-components/SkiaLetter` استفاده می‌کند). مسیر فرض‌شده:
   `assets/fonts/YekanBakh-ExtraBlack.ttf`. اگر مسیر اشتباه باشد Metro هنگام bundle خطای واضح می‌دهد.
3. پکیج جدیدی لازم نیست (فقط Skia، Reanimated، Gesture Handler و react-navigation که از قبل نصب‌اند).
   بعد از جایگزینی یک بار کش Metro را پاک کنید: `npx react-native start --reset-cache`
4. پوشه‌ی `functions/` بدون تغییر است.
5. اختیاری: فونت با import شدن این ماژول خودکار بارگذاری می‌شود. اگر بخواهید زودتر شروع شود، در شروع اپ یا
   صفحه‌ی انتخاب مرحله صدا بزنید:
   ```js
   import { preloadConnectingLetters } from '../components/connecting-letters/ConnectingLetters';
   preloadConnectingLetters();
   ```

## تغییرات نسخه‌ی ۲ (کندی شروع، راهنما، نشستن کلمه)

**۱. کندی بارگذاری اولیه** — سه علت داشت:
- `useTypeface` خودِ Skia در هر بار باز شدن صفحه فایل فونت را دوباره می‌خواند و parse می‌کرد، پس حروف
  دیرتر از بقیه‌ی صفحه ظاهر می‌شدند. حالا فونت یک بار برای کل عمر اپ بارگذاری و نگه داشته می‌شود
  (`utils/letterFont.ts`) و از لحظه‌ی import ماژول شروع می‌شود.
- در Reanimated 3 خواندن `.value` روی JS thread یک رفت‌وبرگشتِ همزمان به UI thread است و هر
  `useDerivedValue`/`useAnimatedStyle` یک بار هنگام mount روی JS اجرا می‌شود. نسخه‌ی قبل چند تا از این‌ها
  برای هر کارت و هر خانه داشت؛ برای یک معمای ۷ کلمه‌ای یعنی بیش از ۲۰۰ خواندن همزمان. وسط انیمیشن باز شدن
  صفحه که UI thread مشغول است، همین خواندن‌ها باز شدن را کند می‌کرد. حالا کل صفحه‌ی بازی **یک** مقدار متحرک دارد و کل خانه‌ها هم **یک**؛ طرح
  هر کارت یک بار به شکل `SkPicture` ضبط می‌شود و مقدار اولیه‌ی همه‌ی انیمیشن‌ها بدون خواندن از UI thread
  ساخته می‌شود (`utils/worklet.ts`).
- انیمیشن ورود پله‌پله‌ی کارت‌ها (تا حدود نیم ثانیه) حذف شد؛ کارت‌ها از فریم اول کامل دیده می‌شوند.

**۲. دیر نمایش داده شدن حرف راهنما** — حرف بعد از یک رندر React و با fade-in ۳۸۰ میلی‌ثانیه‌ای ظاهر
می‌شد. حالا دکمه‌ی راهنما مستقیم یک مقدار روی UI thread را تغییر می‌دهد و حرف در **فریم بعد** کامل دیده
می‌شود (با یک پرش کوتاه). ذخیره در Realm بعد از نمایش انجام می‌شود.

**۳. دیر نشستن کلمه در خانه‌ها** — سه چیز پشت هم بود: ذخیره‌ی Realm (برای کلمه‌ی اصلی دو بار: کلمه و پایان
معما) قبل از رندر روی JS thread اجرا می‌شد، انیمیشن تازه بعد از رندر React شروع می‌شد، و خودِ انیمیشن حدود
یک ثانیه بود. حالا:
- انیمیشن نشستن همان لحظه روی UI thread شروع می‌شود و ذخیره‌سازی‌ها بعد از فریم بعدی انجام می‌شوند.
- انیمیشن کوتاه‌تر است: حرف اول حدود ۱۲۰ میلی‌ثانیه بعد کامل است و کل یک کلمه‌ی ۵ حرفی حدود نیم ثانیه.
- **کلمه‌ی کامل منتظر تایمر نمی‌ماند:** وقتی حروف انتخاب‌شده یک کلمه‌ی معما را کامل کنند و آن کلمه پیشوندِ
  کلمه‌ی بلندتری در معما نباشد، همان لحظه ثبت می‌شود (قبلاً همیشه ۲.۵ ثانیه منتظر تایمر می‌ماند). اگر رفتار
  قبلی را می‌خواهید، در `constants/constants.ts` مقدار `SUBMIT_COMPLETE_WORDS_INSTANTLY` را `false` کنید.

## چه چیزهایی عوض شد

### چیدمان خانه‌های کلمات (مشکلی که گفتید)
قبلاً کلمه‌ها در دسته‌های ۶تایی تقسیم می‌شدند (۷ کلمه = ۶ + ۱). حالا:
- ستون‌ها **متوازن** هستند: ۷ → ۴ + ۳، ۱۰ → ۵ + ۵، ۱۳ → ۵ + ۴ + ۴ (تفاوت ستون‌ها حداکثر یک کلمه).
- تعداد ستون‌ها خودکار انتخاب می‌شود تا **بزرگ‌ترین خانه‌ها** در فضای موجود جا شوند (هیچ ستونی بیشتر از ۶
  کلمه ندارد؛ اگر ستون بیشتر خانه‌ها را حداقل ۱۴٪ بزرگ‌تر نکند، ستون کمتر انتخاب می‌شود).
- چیدمان راست‌به‌چپ است: ستون اول سمت راست، کلمه‌ها در ستون راست‌چین.
- خانه‌ها هیچ‌وقت با دکمه‌ی «کلمات پنهان» هم‌پوشانی ندارند.
- ثابت‌های قابل تنظیم بالای `logic/slotsLayout.ts` هستند (`MAX_ROWS`، `FEWER_COLUMNS_BIAS` و ...).

### کارایی
- **یک Canvas برای کل صفحه‌ی بازی.** قبلاً هر کارت یک `TouchableOpacity` + `ImageBackground` + یک Canvas
  جدای Skia (در `SkiaLetter`) بود و `width`/`height`/`zIndex`/`elevation` هر فریم تغییر می‌کرد که یعنی
  محاسبه‌ی layout در هر فریم. حالا همه‌ی کارت‌ها در یک Canvas کشیده می‌شوند و فقط transform تغییر می‌کند.
- کل وضعیت فیزیک در **یک آرایه‌ی فشرده** است و هر فریم فقط **یک** به‌روزرسانی shared value انجام می‌شود،
  بدون هیچ تخصیص حافظه.
- انتخاب کارت، تایمر و ثبت کلمه همه روی **UI thread** هستند؛ تایمرِ نوار و ثبت کلمه یک انیمیشن واحدند و
  دیگر جدا از هم کار نمی‌کنند.
- انتخاب هر حرف فقط نوار «کلمه‌ی فعلی» را رندر می‌کند، نه هدر و سکه‌ها و خانه‌ها را (قبلاً هر لمس همه را
  دوباره رندر می‌کرد). پیدا شدن کلمه و راهنما اصلاً رندر React ندارند.
- وقتی صفحه‌ی دیگری روی بازی باز است، فیزیک متوقف می‌شود (صرفه‌جویی در باتری).
- خانه‌های کلمات هم روی یک Canvas کشیده می‌شوند (قبلاً هر خانه یک View با متن SVG بود).

### ظاهر
- صفحه‌ی بازی شیشه‌ای تیره با قاب طلایی، درخشش مرکزی، سایه‌ی داخلی و شبکه‌ی نقطه‌ای کم‌رنگ.
- کارت‌های براق سه‌بعدی با حرف برجسته.
- کارت انتخاب‌شده بنفش می‌شود، با فنر کوچک می‌شود (حول مرکز خودش، نه گوشه‌ی بالا-چپ) و از زیر بقیه رد
  می‌شود؛ یک حلقه‌ی طلایی از آن بیرون می‌زند.
- پیدا شدن کلمه: خانه‌ها یکی‌یکی از راست به چپ «پاپ» می‌شوند. حرف راهنما با رنگ طلایی ظاهر می‌شود.
- نوار کلمه‌ی فعلی: سبز با پرش (درست)، قرمز با لرزش (غلط)، آبی با تکان (تکراری).
- نوار تایمر از سبز به نارنجی و قرمز خالی می‌شود.
- **چندلمسی:** می‌شود با هر دو شست حرف انتخاب کرد.

### باگ‌های رفع‌شده
- رنگ بازخورد با `interpolateColor` روی حالت‌های ۰/۱/۲/۳ انیمیت می‌شد؛ مسیر «عادی → غلط» از «سبز» عبور
  می‌کرد و پاسخ غلط لحظه‌ای سبز دیده می‌شد.
- `completedOperation` داخل تابع updater در `setState` صدا زده می‌شد (در StrictMode/رندر همزمان ممکن است دو
  بار اجرا شود). حالا تضمین شده دقیقاً یک بار صدا زده شود.
- دیواره‌ها جهت سرعت را بدون توجه به جهت حرکت برعکس می‌کردند؛ کارتی که با یک برخورد به پشت دیواره هل داده
  می‌شد ممکن بود همان‌جا گیر کند و بلرزد.
- فیزیک به آرایه‌ای در `useRef` وابسته بود که فقط به‌خاطر ترتیب اجرای effectها درست به worklet می‌رسید.
- `HiddenWords`: لمس سریع چندباره‌ی «تبدیل به سکه» جایزه را چند بار پرداخت می‌کرد.
- `TopHeader`: اگر `time_limit` برابر 0 بود، عدد 0 بیرون از `<Text>` رندر می‌شد (کرش).
- `word-game`: راهنما از `additional_words` + `word` استفاده می‌کرد ولی نمایش از `words`؛ حالا یکی شده‌اند.
  کلمه‌های ذخیره‌شده در `words_builded` هم خوانده می‌شوند.
- تایمر راهنمای شروع بازی (guide) هنگام خروج از صفحه پاک نمی‌شد.
- نرمال‌سازی کلمه علاوه بر «آ» حالا «ي» و «ك» عربی و نیم‌فاصله را هم پوشش می‌دهد.
- ابعاد از `Dimensions.get('screen')` در زمان import خوانده می‌شد؛ حالا از `useWindowDimensions`.
